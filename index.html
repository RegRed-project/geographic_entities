How to find your geographic entity:
  • Looking for a country (ADM0)? → geoBoundaries: country
  • Looking for a state/province (ADM1)? → geoBoundaries: stateProvince
  • Looking for a county (ADM2)? → geoBoundaries: county
  • Looking for a protected area? → WDPA - version Sep 2025
  • Looking for an island? Try in order:
    1. geoBoundaries: country (if it's a country)
    2. geoBoundaries: stateProvince (if it's a lower region)
    3. geoBoundaries: county (if it's smaller)
  • Looking for an administrative unit smaller than a county (ADM2)? Check if it was already created→ Additional administrative localities
  • Custom regions that are not a proper administrative unit can be found in → Custom regions

If you didn't find what you were looking for, please send an email with the name of the locality and a picture/screenshot of an accompanying map (if available) to ortega_solis@fzp.czu.cz

If you find an error, please send an email explaining the error to ortega_solis@fzp.czu.cz

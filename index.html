Case Preferred sheet -If you are looking for a country (ADM0) geoboundaries_country -If you are looking for a second order administrative region (ADM1) geoboundaries_stateProvince -If you are looking for the lowest administrative region possible (ADM2) geoboundaries_county -If you are looking for a protected area wdpa_sep2025 -If you are looking for an island 1) geoboundaries_country if it is a country. 2) geoboundaries_stateProvince if it can be a lower admin region. 3) geoboundaries_county if it is an even smaller region. 4) global_islands if none of the above had the information.
